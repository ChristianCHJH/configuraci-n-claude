Escribir los mensajes de commit siempre en español.

**Why:** Preferencia explícita del usuario — "en español siempre el commit".

**How to apply:** En cualquier `git commit` o sugerencia de mensaje de commit para este proyecto, el subject, body y cualquier texto deben estar en español. Los tipos Conventional Commits (`feat`, `fix`, `chore`, etc.) se mantienen en inglés por convención técnica, pero la descripción va en español.

Ejemplo correcto: `feat(cms): agregar schema de Tina con 6 colecciones bilingües`
Ejemplo incorrecto: `feat(cms): add Tina schema with 6 bilingual collections`
