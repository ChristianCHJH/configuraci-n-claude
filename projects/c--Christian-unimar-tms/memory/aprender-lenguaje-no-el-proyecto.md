Christian estudia JavaScript, TypeScript, Node y NestJS (y React, Angular, Kotlin) para poder leer **cualquier** proyecto, no solo el TMS. El material de estudio (temarios, clases) no guarda rutas de archivos ni números de línea del repositorio.

**Why:** el TMS cambia todos los días; una ruta o línea guardada hoy apunta mañana a código que ya no existe. Lo pidió el 2026-10-06 al revisar los temarios.

**How to apply:** en cada clase, la práctica usa un archivo real que Claude busca ese mismo día en el proyecto abierto; si no hay ninguno, un ejercicio propio. Explicar una línea del código actual cuando la pregunta está bien; lo que no se hace es dejarla fijada en un temario. Ver [[temarios-aprendizaje-tms]].
