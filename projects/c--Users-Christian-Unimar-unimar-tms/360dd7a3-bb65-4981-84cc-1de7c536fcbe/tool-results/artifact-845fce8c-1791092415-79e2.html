    ¿Cuánto toca la lógica?

    Impacta lógica

    Aplicar la solución cambia lo que el sistema hace: qué acepta o rechaza la API, qué datos se guardan, qué puede hacer cada persona en pantalla o qué reciben SAP, XMS o la app.

    No impacta lógica

    El sistema hace exactamente lo mismo después del cambio. Mejora la calidad interna, la seguridad del servidor, las pruebas, la documentación o el despliegue.
