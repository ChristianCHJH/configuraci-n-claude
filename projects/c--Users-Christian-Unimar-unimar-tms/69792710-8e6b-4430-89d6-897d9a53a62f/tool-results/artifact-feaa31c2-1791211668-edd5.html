Reconocer solo si el archivo es una descarga o un embarque

Sin corregir
Recepción › Carga de Archivo › botón «Cargar archivo»
«Aquí puede haber una mejora (…) para que no esté eligiendo el usuario. Pueda reconocer el archivo.»Anaís Valdez, minuto 4:50, al subir una RCE de SAP QAS con fecha del 2

Qué pasa hoy

  1. El modal se abre con la operación Descarga (RD) ya marcada.
  2. La persona suelta su archivo de embarque y no cambia el selector.
  3. El sistema lo rechaza y pide subirlo de nuevo con la operación correcta.

El sistema ya sabe qué tipo de reporte es, porque lo dice en el mensaje de rechazo. Usa ese dato para rechazar y no para resolver el caso.

Dónde está en el código

PiezaArchivoQué hace
Selectorweb/…/carga-archivo/componentes/zona-de-archivo.tsx:10Muestra las dos operaciones para que la persona elija una

Rechazoapi/…/recepcion/application/ingestar-reporte.caso-uso.ts:65Si no coincide, rechaza el archivo en lugar de usar la operación reconocida

Propuesta

El servidor reconoce la operación por los encabezados del Excel y la web quita el selector. Si los encabezados no corresponden a ninguno de los dos reportes, se mantiene el rechazo de hoy. Tiempo estimado: medio día, con las pruebas del reconocimiento y del modal incluidas.

Las capturas se tomaron en el servidor local de desarrollo, con respuestas simuladas. El texto del rechazo es el mismo que arma el servidor real. El archivo de la captura es de ejemplo y no es el que subió Anaís.
