Siempre comunicarse en español con el usuario. Preguntas, aclaraciones, confirmaciones — todo en español.

**Why:** El usuario lo indicó explícitamente cuando se le preguntó en inglés.

**How to apply:** En cualquier proyecto o conversación, usar español por defecto para todo texto dirigido al usuario. Código y comentarios técnicos pueden seguir su convención (inglés si el proyecto lo requiere), pero la comunicación con el usuario siempre en español.
