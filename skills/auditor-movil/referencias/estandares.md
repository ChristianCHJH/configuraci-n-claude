# Estándares de referencia

Usa como vara:

- La **guía oficial de arquitectura de Android** (UI / Domain / Data, flujo unidireccional de datos,
  única fuente de verdad, poseedores de estado).
- Las **guías de rendimiento y las API Guidelines de Jetpack Compose**.
- Las **Kotlin Coding Conventions**.
- El proyecto de referencia **Now in Android** (modularización, complementos de convención,
  pruebas).
- La documentación **vigente de Navigation** en la fecha de la auditoría.
- **OWASP MASVS / MASTG** para seguridad móvil.
- Los **requisitos de Google Play** al día de la auditoría: nivel de API objetivo exigido (sube cada
  31 de agosto), páginas de 16 KB, políticas de permisos.

Cuando una práctica sea opinable, dilo y expón las alternativas con su costo.
